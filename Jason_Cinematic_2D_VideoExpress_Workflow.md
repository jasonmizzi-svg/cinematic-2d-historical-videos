# Jason's Cinematic 2D Historical Story Workflow

## Purpose and standing defaults

Create original, narrated, educational cinematic 2D animated stories using VideoExpress at https://app.videoexpress.ai/. The default audience is teenagers and adults, with accessible English suitable for a classroom or YouTube. Default finished runtime: 180–300 seconds (target 240 seconds), landscape 16:9, Full HD MP4, English narrator Beau Whitaker if available. User-specified runtime, aspect ratio, language, narrator and topic override defaults. Never use a 30-second default. Never default to stick figures, photorealism or 3D.

Use the supplied illustrated reference as the style example: hand-drawn cinematic 2D animation, believable human anatomy and proportions, expressive faces, defined hairstyles, clean linework, cel shading, warm directional lighting, painted layered backgrounds, rich colors and atmospheric perspective. Preserve each supplied character's distinct identity rather than copying the example character into unrelated stories. All characters, including background people, follow a coherent 2D aesthetic.

## 1. Intake and authorization

Ask for the story/topic if missing. If supplied, start with the defaults without repetitive approval pauses. Accept uploaded named character reference images, optional story outline, duration, narration preference and intended audience. Reuse the original approved reference files for named recurring characters when available; request a missing reference rather than claiming to possess it. Respect account permissions, product confirmations and usage limits. Never make a purchase, share publicly, accept binding terms, or change unrelated settings without required authorization. Do not bypass authentication or security controls. Use visible supported browser controls, not private APIs. If a required feature is unavailable, explain the limitation and preserve completed work.

## 2. Historical research and script

For history, verify major dates, places, names, cultural context, motivations, clothing, architecture, chronology and consequences using trustworthy sources (museums, universities, archives, scholarly works). Record source URLs and distinguish documented facts from illustrative reconstruction. Avoid invented quotations presented as fact, anachronisms, glorification of violence, graphic imagery and actionable combat instructions. Depict conflict at a non-graphic historical overview level. Structure the story into a hook, background, key developments, turning point, consequences and a memorable conclusion. Keep narration engaging, accurate, neutral and age-appropriate. Prepare an estimated 400–600 words for a four-minute film, adjusting to the actual voice rate and requested runtime. Use short linked narration beats that fit the supported clip lengths; never compress or cut speech simply to meet duration.

## 3. Character and location bible

Create a register for every named recurring character: ID, name, age, face, hair, complexion, body proportions, wardrobe (period-appropriate where relevant), distinguishing features, personality, source reference file and approved anchor asset ID. Use the supplied reference as identity authority. Create a matching 2D anchor portrait or full-body reference only when needed; never replace a user's existing identity with a random new face. Preserve costume and appearance except for explicitly scripted changes. Supporting characters must have distinct identities. Record recurring locations, stable geography, landmarks, light direction, props and period details; create approved environment reference assets when supported.

## 4. Storyboard and runtime plan

Build an ordered scene ledger before generation: scene ID, narration, estimated seconds, characters and reference IDs, setting, incoming pose/state, visible action, outgoing state, continuity handoff, image prompt, motion prompt, job/asset ID, actual clip duration, cumulative runtime and QA status. Divide the story into approximately 36–60 five-second shots, or an equivalent number using longer supported narration-driven durations. Use actual durations, not fixed estimates, to reach 180–300 seconds; add meaningful story beats or trim surplus visual tails if needed, without filler or lost speech. Vary wide establishing shots, medium interactions, close-up reactions and motivated transitions. Each shot advances the narrative. Maintain screen direction, eyelines, prop ownership, location layout, wardrobe and the previous shot's described endpoint.

## 5. VideoExpress setup

Open the existing signed-in VideoExpress account, Create with AI → Create Video From Prompt when available. Keep the requested project and dialog aspect ratio aligned; select 2D image type. Use the approved character reference via Consistent Character. Verify selected thumbnails and never confuse a source-image selector with the character-reference selector. For multiple characters, use separate character reference slots where supported, prioritizing people visible in the shot; use fixed location descriptions when no extra reference slot is available. Keep references and settings consistent across scenes. Prefer prompt enhancement off, Creative mode off for controlled reference rendering, Advanced Mode off, public gallery off and lipsync off for narrator-led films unless explicitly requested. Verify actual visible controls and adapt only as needed. Do not assume feature labels or settings are permanent.

## 6. Generate each scene

Write a detailed image prompt describing the exact incoming story moment, 2D visual style, character identity and count, costume, poses, eyelines, hands and props, spatial relationship, period context, stable location geometry, camera framing, light and depth. Use the approved identity reference(s); include an environment reference when supported. Visually inspect the candidate for likeness, anatomy, required objects, historical consistency and action-ready staging before animation. Never animate blank or severely defective images.

Write a single coherent visual-motion paragraph in present tense. Describe framing, a motivated camera movement, the visible starting state, one meaningful action, and the ending pose or state that connects to the next shot. Preserve character identity, movement direction, and background geography. Keep spoken narration out of the visual-motion field; use dedicated narration controls instead. Use restrained cinematic pans, tracking shots and push-ins; avoid repeated random camera or character resets.

Select Narration Video (Choose my Audio) or its current equivalent. In the integrated VideoExpress CloneVoice system voice dialog, select Beau Whitaker or the requested verified voice, keep voice, pace and pitch consistent, enter only the scene's narration, generate audio, confirm readiness and submit the narrated video. No standalone CloneVoice site or audio download is needed for this workflow. Do not silently substitute unavailable voices. Use voice cloning only with appropriate consent.

Keep the generation panel open where possible. Work on subsequent shots while earlier jobs render, within the visible account concurrency limit. Record each job immediately; never treat a delay as failure or resubmit a job of unknown status. Correct verified unusable assets with at most three total informed attempts per scene. Preserve accepted work and record unresolved issues. Periodically save checkpoints to permit recovery after interruptions.

## 7. Assembly, quality and saving

Wait for every job to reach a known result. In VideoExpress Media Library, identify accepted clips by scene ID or recorded asset, not newest-first order. Add each once to the timeline in story order from 00:00; maintain its associated narration and avoid duplicate audio playback. Use Auto Align Clips on relevant tracks. Check scene count, timing, transitions, gaps, overlaps, audio synchronization, character appearance and historical details. Review the assembled video and listen to narration whenever controls permit. Resolve material defects using existing accepted assets or bounded corrections; do not claim unsupported checks. Measure final runtime and honor 3–5 minutes by default.

Save the named project inside the user's VideoExpress account at https://app.videoexpress.ai/ and verify the save in the actual project interface. This is required even when an MP4 download is also produced. Export MP4, Full HD 1080p, High quality when included, retaining the requested ratio. Wait for completed export, verify its existence and playback in My Videos, then download through supported controls when available. Preserve the saved editable project. Never interpret an export click or processing badge as verified completion. Do not publish to YouTube or public galleries without authorization.

## 8. Completion report

Report project title, verified VideoExpress save status, actual runtime, ratio, 2D style, voice, scene count, export status, resulting file/link, sources for historical content and any checks or features that were unavailable. If blocked, identify the exact step and what remains; do not claim success. Keep the character bible and production ledger available for revisions and future stories. Retain this workflow independently of the upstream original; update it only on the user's request.
