# Using the workflow in ChatGPT

1. Open a chat with access to supported browser controls.
2. Copy the launch paragraph from [SYSTEM_PROMPT.md](SYSTEM_PROMPT.md) into it.
3. Attach your named character illustration references and provide the historical topic or story.
4. Sign in to [VideoExpress](https://app.videoexpress.ai/) if requested; complete any required account confirmations yourself.
5. The assistant uses the [full workflow](Jason_Cinematic_2D_VideoExpress_Workflow.md) to generate, assemble, save and export the project. If browser control is unavailable, use a supported browser-capable session; do not weaken security protections to force a workflow to run.
