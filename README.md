# Jason's Cinematic 2D Historical Videos

A personalised VideoExpress workflow for cinematic illustrated 2D historical stories and educational videos. This fork adapts the original [Realistic Consistent Character Videos](https://github.com/ai-playbooks/realistic-consistent-character-videos) workflow into a longer narrated format.

## Quick start

1. Open [SYSTEM_PROMPT.md](SYSTEM_PROMPT.md) and copy the launch paragraph into a new browser-capable ChatGPT conversation.
2. Attach your character reference illustrations and state the story/topic. Optionally specify length, voice or aspect ratio.
3. The assistant follows the [full customised workflow](Jason_Cinematic_2D_VideoExpress_Workflow.md), using [VideoExpress](https://app.videoexpress.ai/) to create, assemble, save and export the film.

## Defaults

| Feature | Setting |
|---|---|
| Runtime | 3–5 minutes (target 4) |
| Style | Cinematic illustrated 2D characters, not stick figures or 3D |
| Format | Landscape 16:9 |
| Character continuity | Uploaded reference images and consistent character bible |
| Narration | Integrated CloneVoice, Beau Whitaker when available |
| Historical accuracy | Verified facts, period detail and source list |
| Output | Saved editable VideoExpress project and verified Full HD MP4 export |
